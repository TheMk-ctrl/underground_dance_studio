# Underground Dance Studio — лендинг

Одностраничный сайт-визитка для школы танцев в Воронеже: направления, цены, отзывы, адреса филиалов и запись на пробное занятие. Сделан как демо для заказчика перед запуском полноценного проекта.

🔗 **Демо:** https://claude.ai/artifact/KSvU1uyqAhNjEpnzvHP5UG

## Возможности

- Адаптивная вёрстка — от мобильного до десктопа
- Карточки направлений (hip-hop, house, dancehall, vogue, waacking, акробатика, актёрское мастерство)
- Блок абонементов с ценами и скидками
- Отзывы и рейтинг, подтянутые с Google-карточки студии
- Оба филиала с адресами, телефонами и временем работы
- Плавное появление блоков при скролле и анимация на загрузке главного экрана, с уважением к `prefers-reduced-motion`
- Один HTML-файл, без сборки и зависимостей — открывается прямо в браузере

## Технологии

- Чистый HTML / CSS / JS (без фреймворков)
- Google Fonts: Unbounded + Manrope
- IntersectionObserver для скролл-анимаций

## Структура

```
underground.html   — вся страница: разметка, стили и скрипт в одном файле
```

## Запуск

Файл самодостаточный — просто открыть `underground.html` в браузере. Сервер или сборка не нужны.
